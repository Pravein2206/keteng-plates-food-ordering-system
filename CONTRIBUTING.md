# Contributing

## Branch naming
Use the following branch naming convention:

- feature/usXX-name
- bugfix/usXX-name
- chore/task-name

Examples:

```bash
git checkout -b feature/us01-menu
```

## Pull requests
- Create a small, focused pull request.
- Keep commits small and descriptive.
- Ensure at least 1 reviewer is assigned before merging.
- Link the related issue using `Closes #<issue-number>`.
- Keep the PR scope limited to the story or task being implemented.

## Review expectations
- Reviewers should check acceptance criteria, test evidence, and impact.
- Do not merge without a reviewer approval.
- If a story is blocked, label it with `blocked` and document the blocker.

## Commit discipline
- Prefer small, incremental commits.
- Keep commit messages clear and specific.
- Avoid mixing unrelated changes in one commit.
